---
name: Parent intake completeness
description: Scholix parent signup details and approval requirements.
---

Parent signup must collect a parent or guardian contact address separately from each student's lesson address, and require an explicit answer for what brought the parent to Scholix. Incomplete legacy or reapplication accounts must complete those required details before admin approval.

**Why:** the user requested complete, explicit parent intake to support safe account review and booking.

**How to apply:** keep signup, pending-parent profile completion, and the admin approval gate aligned whenever parent intake fields or workflows change.
